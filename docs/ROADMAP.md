# Roadmap

Public summary of where the portfolio is heading. Released work is in [CHANGELOG.md](../CHANGELOG.md); this file only lists what is still open. Contributions on any item are welcome: open an issue first to agree on scope.

## Phase 2: quality and automation

- **Lighthouse CI in the pipeline:** fail the build when any category drops below 95.
- **CV generated from site data:** build the PDF from `experience.ts` and the certifications instead of maintaining it by hand.
- **Live demos:** link running demos for IterView-AI and API Colores from their project cards.

## Phase 3: content and credibility

- **Credly sync:** evaluate whether certifications can be pulled from Credly.
- **Publications and academic background** section.
- **Verifiable testimonials and recommendations.**
- **Automated WCAG accessibility audit.**
- **Case studies** with an architecture diagram.

## Backlog

- **Technical blog** with an MDX architecture.
- **Contact integration** (Formspree form or Calendly embed).
- **Interactive API showcase** (live endpoints or Swagger).
- **E2E tests with Playwright** (navigation, i18n, forms).
